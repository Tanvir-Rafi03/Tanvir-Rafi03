## `06 //` COMMAND_PALETTE

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>⌘</kbd> + <kbd>K</kbd>) anywhere on the site.

| Group | Commands |
|:--|:--|
| `NAVIGATE` | Home · About · Projects · Services · Contact |
| `CONNECT` | Open GitHub · Open LinkedIn · Copy Email · Copy Phone |
| `SYSTEM` | Scroll to Top · Trigger Glitch · System Info |

<kbd>↑</kbd> <kbd>↓</kbd> to move · <kbd>Enter</kbd> to run · <kbd>Esc</kbd> to close

## `07 //` ARCHITECTURE

<details>
<summary><b><code>▸ EXPAND FILE TREE</code></b></summary>

<br>

```
Portfolio/
├── public/
│   ├── icon.png                 # favicon
│   ├── img3.png                 # profile — front face
│   └── img4.png                 # profile — flip face
├── src/
│   ├── main.jsx                 # React root
│   ├── App.jsx                  # Lenis · reveal observer · scroll bar · layout
│   ├── components/
│   │   ├── BootScreen.jsx       # CRT decrypt boot sequence
│   │   ├── ParticleNet.jsx      # canvas constellation background
│   │   ├── Cursor.jsx           # custom HUD cursor
│   │   ├── Header.jsx           # nav + mobile hamburger
│   │   ├── ScrollHUD.jsx        # section tracker + progress rail
│   │   ├── CommandPalette.jsx   # Ctrl+K launcher
│   │   └── ActivityMonitor.jsx  # floating telemetry widget
│   └── pages/
│       ├── Hero/                # UnicornScene + typewriter roles + HUD
│       ├── About/               # flip photo card, stats, Skills marquee
│       ├── Project/             # filterable 3D-tilt project grid
│       ├── Services/            # service cards with live code snippets
│       ├── Contact/             # Formspree form + socials
│       └── Footer/              # brand, nav, live clock
├── index.html
└── vite.config.js
```

</details>

Each component owns its own stylesheet. No CSS framework, no animation
library — every transition is hand-written CSS or `requestAnimationFrame`,
throttled to one update per frame and kept on the compositor
(`transform` / `opacity` only, never layout).

## `08 //` LOCAL_DEPLOY

```bash
# ── clone the deck ────────────────────────────────
git clone https://github.com/Tanvir-Rafi03/Portfolio.git
cd Portfolio

# ── install dependencies ──────────────────────────
npm install

# ── boot dev server → http://localhost:5173 ───────
npm run dev

# ── production build ──────────────────────────────
npm run build
npm run preview

# ── lint ──────────────────────────────────────────
npm run lint
```

> **Requires** Node.js 20.19+ or 22.12+ (Vite 7 minimum).
